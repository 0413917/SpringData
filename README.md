# Spring Boot Project&#x20;

## About

This project is a Spring Boot application designed to manage employees and departments.

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven

## Features

- Add Employee
- Update Employee
- Delete Employee
- Display All Employees
- Manage Departments

- ##Design Patterns

- Singltone

## Requirements

- JDK 17 or later
- Maven
- MySQL

## Installation

1. Clone the repository:

   ```bash
   git clone REPOSITORY_URL
   ```

2. Open the project using IntelliJ IDEA.

3. Configure your database in `application.properties`.

4. Run the Spring Boot application.
